# Apex Projects Collection

This repository is a consolidated collection of all Apex-related projects, combining five separate repositories into one organized structure. Each project is maintained in its own directory with its complete history preserved.

## 📁 Repository Structure

1. **Apex Main** (`/apex-main/`)
   - The primary Apex project containing core functionality
   - Original repository: [K007-K/Apex](https://github.com/K007-K/Apex)
   - Contains: Core Apex classes and configuration

2. **Apex Task 2** (`/apex-task2/`)
   - Second task implementation in the Apex series
   - Original repository: [K007-K/Apex-Task-2](https://github.com/K007-K/Apex-Task-2)
   - Contains: Task 2 implementation and related files

3. **Apex Task 3** (`/apex-task3/`)
   - Third task in the Apex series
   - Original repository: [K007-K/Apex-Task-3](https://github.com/K007-K/Apex-Task-3)
   - Contains: Task 3 implementation and related files

4. **Apex Task 4** (`/apex-task4/`)
   - Fourth task implementation
   - Original repository: [K007-K/Apex-Task-4](https://github.com/K007-K/Apex-Task-4)
   - Contains: Task 4 implementation and related files

5. **Apex Task 5** (`/apex-task5/`)
   - Fifth and final task in the series
   - Original repository: [K007-K/Apex-Task---5](https://github.com/K007-K/Apex-Task---5)
   - Contains: Task 5 implementation and related files

## 🚀 Getting Started

Each project is self-contained in its own directory. Navigate to the specific project directory to view or work with that particular task.

```bash
git clone https://github.com/K007-K/Apex-Merged.git
cd Apex-Merged
```
